宮崎大学 学生個人開発プロジェクト

知らない。忘れる。迷う。
大学生活から、それをなくす。

シラバスには載らない出席の厳しさや課題量――先輩や友達の口コミ頼りだった情報を、 「授業カルテ」としてみんなで蓄積・共有する、宮崎大学の学生専用アプリです。

できることを見る 開発者に連絡する
00 / Problem

大学生活は「知らない」「忘れる」「迷う」の連続

公式サイトやシラバスだけでは分からない情報が多く、学生同士の口コミや先輩の伝聞に依存しているのが実情です。

知らない

出席・課題のリアルが見えない

出席確認の厳しさ、課題の量、試験形式――シラバスには載らない情報が多い。

忘れる

締切や欠席の上限を見失う

レポート締切、次回の小テスト予告、あと何回欠席できるかを把握しきれない。

迷う

履修判断の材料がない

この授業を取ると時間割・生活リズムがどう変わるのか、事前に判断しづらい。

01 / 授業カルテ

宮大生のリアルな授業情報を、みんなで蓄積する

中心にあるのは「授業カルテ」。実際に授業を受けた学生のリアルな声を、匿名で・宮崎大学限定で蓄積します。出席の厳しさ・課題量・試験の難易度・授業の分かりやすさを5段階で評価。自由記述で「実際に受けてみてどうだったか」も蓄積されます。

  • 宮崎大学に限定した匿名コミュニティなので投稿のハードルが低い
  • 出席確認方法など、履修前に知りたい情報を一覧で確認
  • みんなの声タブで、生の感想をそのまま読める
02 / 時間割

公開シラバスと連携した時間割登録

宮崎大学の公開シラバスと連携し、検索・一覧選択で授業を時間割に登録。1〜5限の実際の時間帯がそのまま反映されます。

  • 授業名で検索してタップするだけで登録完了
  • シラバスにない授業は手動入力にも対応
  • CSVでのインポート・エクスポートも可能
03 / 日々の管理

欠席管理と「今日やること」

科目ごとの欠席上限に対する残り回数を自動計算。時間割・欠席・メモ・タスクを1つの画面に統合し、毎日の行動を整理します。

  • あと何回休めるかがひと目で分かる進捗バー表示
  • 今日の予定とタスクをホーム画面にまとめて表示
  • 授業ごとのメモ・次回予告も記録できる

05 / Roadmap

授業カルテ → 日常利用 → 履修判断 → 友人ネットワーク

まずは宮崎大学という小さな市場でPMFを検証し、学生生活の一次情報を資産として蓄積していきます。
